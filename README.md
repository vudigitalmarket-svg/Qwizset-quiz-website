# Qwizset – Skills Assessment Platform

Qwizset is a responsive web-based skills assessment platform designed to help users evaluate their knowledge across different technology-related fields through structured, timed multiple-choice assessments.

## About the Project

The platform allows users to test their knowledge, answer questions within a set time limit, and review their performance after completing an assessment.

Qwizset aims to provide a simple, accessible, and user-friendly assessment experience across different screen sizes.

## Features

- **Multiple Skill Categories:** Assessments covering Web Development, Digital Marketing, UI/UX Design, Cybersecurity, and Data Analysis.
- **Timed Assessments:** Five multiple-choice questions per assessment.
- **Question Navigation:** Navigate between questions during an assessment.
- **Answer Tracking:** Keep track of answered questions.
- **Automatic Scoring:** Calculate scores based on submitted answers.
- **Results and Feedback:** View performance after completing an assessment.
- **Answer Review:** Review submitted answers and their explanations.
- **Retake Option:** Attempt an assessment again.
- **Responsive Design:** Layouts optimized for desktop, tablet, and mobile devices.

## Technologies Used

- HTML5 – Structure and content.
- CSS3 – Styling and responsive layouts.
- JavaScript – Assessment functionality, timer, navigation, and score calculation.
- JSON – Storage of assessment questions and data.
- Git and GitHub – Version control and project collaboration.
