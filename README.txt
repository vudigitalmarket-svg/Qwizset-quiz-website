QWIZSET - UPDATED MVP FILES

Files:
- index.html: updated homepage copy and practical skill cards.
- style.css: your original stylesheet retained unchanged.
- script.js: your original mobile navigation JavaScript retained unchanged.
- practice.html: assessment setup, question, and results screens.
- practice.css: your original stylesheet plus small supporting styles for the new states.
- practice.js: assessment logic (loads JSON, skill selection, questions, navigation, timer, scoring, answer review, retake).
- qwiz.json: five skill areas, five questions each.

HOW TO RUN:
1. Keep all these files in the same project folder.
2. Keep your existing assets folder alongside them.
3. Open the folder in VS Code.
4. Run index.html with the Live Server extension (recommended). Do not open practice.html directly with file:// because fetch() may be blocked by the browser.
5. Select a skill card or click Get Started, choose a skill and begin.

IMPORTANT:
- The current question bank contains original foundational multiple-choice questions for demonstration and learning. It is not an official certification or a hands-on practical test.
- The timer is 10 minutes per skill area.
- The project currently has no login, database, or saved user history; scores are shown on the results screen only.
